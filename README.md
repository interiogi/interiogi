**Evidência**

### Estado atual

|---|---|---|
| **ISI Core** | Protótipo | Python, JSON, regras, casos de uso e documentação |
| **BioSolution / EcoSolution** | Caso histórico operacional | Fluxos, checklists, registros, procedimentos e aprendizados |

| **Infraestrutura Territorial Interiogi** | Visão arquitetural / conceito | Arquiteturas, mapas, requisitos e validação futura por componentes |

### Regras de evidência

- conceito não é implementação;
- experimento não é produto;
- protótipo não é operação real;
- código não comprova implantação;
- implantação não comprova resultado;
- resultado exige evidência;
- nenhuma imagem conceitual substitui implementação real.

Cada novo repositório deverá, quando aplicável, documentar:

- problema;
- contexto;
- usuários;
- objetivo;
- requisitos;
- arquitetura;
- tecnologias utilizadas;
- decisões;
- estágio atual;
- instalação ou execução;
- testes;
- evidências;
- limitações;
- aprendizados;
- próximos passos.

## 🌿 Tecnologia Centrada no Humano

A tecnologia no Interiogi deve servir pessoas e necessidades reais.

Os principais critérios de projeto incluem:

### Humano no centro

- dignidade;
- respeito;
- autonomia;
- consentimento;
- acessibilidade;
- inclusão;
- clareza;
- possibilidade de controle.

### Ética e segurança

- privacidade;
- proteção de dados;
- transparência;
- segurança;
- explicabilidade;
- uso responsável de IA;
- identificação de vieses.

### Sustentabilidade

- eficiência;
- redução de desperdícios;
- responsabilidade ambiental;
- circularidade;
- regeneração;
- integração responsável com a natureza.

### Tecnologia com propósito

Uma solução não deve ser avaliada somente pela pergunta:

> **Funciona?**

Também deve responder:

- Para quem funciona?
- Qual problema resolve?
- Quem pode ficar de fora?
- Quais dados utiliza?
- Qual impacto humano produz?
- Qual impacto ambiental produz?
- É compreensível?
- É segura?
- É acessível?
- Pode ser melhorada?
- Existe evidência do resultado?
